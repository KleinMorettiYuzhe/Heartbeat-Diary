# Heartbeat-Diary
《心动日记》使用须知  
一、运行方式 
    本程序为单个网页文件，双击即用浏览器打开，无需安装、可离线运行。建议使用新版 Edge 或 Chrome。 
二、日记存储  
    1. 日记保存在本机浏览器本地存储中，仅限当前电脑、当前浏览器使用。 
    2. 清理浏览器数据（Cookie 及站点数据）将导致日记全部丢失且无法恢复；无痕模式下不保存。 
    3. 换浏览器或换电脑后池子为空，请提前导出备份。
三、分享版本   
    1. 分享版为导出时刻的快照，之后新写内容不包含在内。 
    2. 分享版仅供观看，接收方无法写入或删除。 
    3. 文件为明文网页，不设密码，请勿包含不宜公开的内容。 
四、使用建议 
    定期点击「生成分享版」留存备份；删除操作即时生效，请谨慎确认。
